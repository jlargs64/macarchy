## 0.1.0 (2026-09-22)

First tagged release. Everything before this was untagged history on `main`.

### Features

* **theme:** `theme-set` restyles Ghostty, Zellij, Neovim, SketchyBar, JankyBorders and the wallpaper together; 22 themes ship, 16 ported from Omarchy with `theme-port`
* **theme:** `theme-pick`, an fzf picker with truecolor swatches (`shift + alt - /`)
* **windows:** yabai + skhd + SketchyBar + JankyBorders over native Spaces, no SIP changes
* **keys:** `macarchy-keys`, a searchable which-key popup of every binding (`alt - /`)
* **agent:** `ws`, plain-English and voice control of windows, Spaces, theme and tabs through the on-device Needle model
* **agent:** `ws --voice` records the default mic through Handy, with an overlay and mic/camera glyphs in the bar
* **install:** `install.sh` adopts an existing Handy.app; `install-agent.sh` for the agentic install path
* **update:** `macarchy-update` pulls, relinks new files, prunes dead links and reloads only what changed; `--login on` runs it at every login

### Fixes

* **theme:** reload Ghostty with SIGUSR2 instead of focusing it
* **ws:** refresh the bar's space indicators after running commands
